LECTURE 2

Variables, Data Types & Operators

المتغيرات والأنواع والعمليات

1. المتغيرات Variables

المتغير حاوية تحمل اسماً وتخزن قيمة في ذاكرة الحاسوب لاستخدامها لاحقاً. نستخدم علامة الإسناد =.

age = 20
name = "Sara"
price = 4.75
print(name, age, price)

x = 5
x = x + 1
print(x)  # 6

a, b, c = 1, 2, 3
a, b = b, a
print(a, b)  # 2 1

قواعد تسمية المتغيرات

  • تستخدم الحروف والأرقام والشرطة السفلية _.
  • لا يبدأ الاسم برقم.
  • الأسماء حساسة لحالة الأحرف: age يختلف عن Age.
  • لا تستخدم الكلمات المحجوزة مثل class وif وfor وTrue.
  • يفضل اسم واضح وبصيغة snake_case مثل student_name.
Python تستخدم Dynamic Typing؛ لا نحتاج إلى تحديد نوع المتغير مسبقاً، والنوع يُفهم من القيمة.

5. المقارنة والمنطق

المقارنة تنتج True أو False:

== يساوي · != لا يساوي · > أكبر · < أصغر · >= أكبر أو يساوي · <= أصغر أو يساوي

المعاملات المنطقية: and (كلا الشرطين صحيح)، or (واحد على الأقل صحيح)، not (يعكس القيمة).

age = 20
has_id = True
print(age >= 18 and has_id) # True
print(age < 18 or age > 60) # False
print(not has_id)           # False
print(1 < age < 30)         # True

6. اختصارات الإسناد

x += 5 تعني x = x + 5، وكذلك -= و*= و/= و%= و**=. لا يوجد ++ أو -- في Python.

7. تنسيق f-strings

name = "Sara"
age = 20
print(f"Hello {name}, you are {age} years old.")

price = 4.5
print(f"The price is {price:.2f} dollars")
# The price is 4.50 dollars

:.2f منزلتان عشريتان، :.0f دون منازل، و:, فاصل الآلاف.

LECTURE 3

Conditional Statements

الجمل الشرطية

1. اتخاذ القرار

الجملة الشرطية تجعل البرنامج يختار الأسطر التي ينفذها اعتماداً على شرط نتيجته True أو False.

2. if

تنفذ الكتلة فقط عندما يكون الشرط صحيحاً. يجب وضع النقطتين : ثم إزاحة الأسطر التابعة بمقدار 4 مسافات.

age = int(input("Enter your age: "))
if age >= 18:
    print("You are an adult.")
print("Program finished.")

3. if-else

تستخدم عندما يوجد مساران: إذا تحقق الشرط ينفذ if، وإلا ينفذ else.

number = int(input("Enter a whole number: "))
if number % 2 == 0:
    print(f"{number} is even")
else:
    print(f"{number} is odd")

4. if-elif-else

تستخدم لأكثر من احتمال. يفحص Python الشروط من الأعلى إلى الأسفل وينفذ أول شرط صحيح فقط؛ لذلك نضع الشرط الأكثر تحديداً أولاً.

score = int(input("Enter your score: "))
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"
print(f"Your grade is {grade}")

5. الشروط المتداخلة

يمكن وضع if داخل if، مثل التحقق من العمر ثم التحقق من وجود هوية.

age = 20
has_id = False
if age >= 18:
    if has_id:
        print("Enter")
    else:
        print("ID required")
else:
    print("Denied")

6. Truthiness

القيم 0 والنص الفارغ "" تعتبر False، والنص غير الفارغ مثل "hello" يعتبر True عند استخدامه كشرط.

7. التعبير الشرطي المختصر

age = 20
status = "adult" if age >= 18 else "minor"
print(status)  # adult

8. match-case (اختياري)

متاح من Python 3.10، لمقارنة متغير مع قيم ثابتة متعددة. الرمز _ يمثل الحالة الافتراضية.

choice = input("Choose a, b or c: ")
match choice:
    case "a":
        print("You chose A")
    case "b":
        print("You chose B")
    case "c":
        print("You chose C")
    case _:
        print("Invalid choice")

9. أخطاء شائعة

  • نسيان النقطتين بعد if.
  • نسيان الإزاحة داخل الكتلة.
  • استخدام = للمقارنة بدلاً من ==.
  • مقارنة input() النصي مع رقم دون تحويله إلى int.
  • كتابة if day == "Sat" or "Sun"؛ الصحيح تكرار المقارنة في الطرفين.
  • وضع شرط عام قبل شرط أكثر تحديداً في elif.

10. أمثلة المحاضرة

آلة حاسبة تتجنب القسمة على صفر

num1 = float(input("First number: "))
op = input("Operator (+, -, *, /): ")
num2 = float(input("Second number: "))

if op == "+":
    print(f"Result = {num1 + num2}")
elif op == "-":
    print(f"Result = {num1 - num2}")
elif op == "*":
    print(f"Result = {num1 * num2}")
elif op == "/":
    if num2 == 0:

    else:

else:
    print("Invalid operator.")

year = int(input("Enter a year: "))
if (year % 4 == 0 and year % 100 != 0) or year % 400 == 0:

    print(f"{year} is not a leap year.")

LECTURE 4

Loops: while and for

الحلقات التكرارية

1. لماذا نستخدم الحلقات؟

الحلقة تكرر مجموعة أوامر دون كتابة الأوامر نفسها مرات متعددة. كل تكرار يسمى Iteration.

whilefor
عندما يستمر التكرار ما دام الشرط True، وعدد المرات غير معروف مسبقاً.عندما نعرف عدد مرات التكرار أو نريد المرور على عناصر تسلسل.

2. while

يفحص الشرط قبل كل تكرار. كل حلقة while سليمة تتكون من قيمة بداية وشرط وتحديث يجعل الشرط يصبح False.

count = 1
while count <= 5:
    print(count)
    count += 1
print("Done")

الناتج: 1 ثم 2 ثم 3 ثم 4 ثم 5 ثم Done. نسيان التحديث قد يسبب Infinite Loop.

3. while مع إدخال المستخدم

password = input("Enter the password: ")
while password != "python123":
    print("Wrong password. Try again.")
    password = input("Enter the password: ")
print("Access granted!")

قيمة Sentinel هي قيمة خاصة توقف الحلقة، مثل إدخال 0.

total = 0
number = int(input("Number (0 to stop): "))
while number != 0:
    total += number
    number = int(input("Number (0 to stop): "))
print(f"Total = {total}")

4. for و range()

تمر حلقة for على عناصر التسلسل واحداً بعد الآخر. الدالة range لها ثلاث صيغ:

الصيغةالقيم
range(5)0, 1, 2, 3, 4
range(1, 6)1, 2, 3, 4, 5
range(0, 10, 2)0, 2, 4, 6, 8
range(5, 0, -1)5, 4, 3, 2, 1
for i in range(1, 6):
    print(i)

total = 0
for i in range(1, 101):
    total += i
print(f"The sum is {total}") # 5050

المرور على النص

for letter in "Python":
    print(letter)
print("a" in "banana") # True
print("z" in "banana") # False

متى أختار for أو while؟

  • عدد تكرارات معروف: for مع range().
  • المرور على أحرف نص: for.
  • الاستمرار حتى يحدث أمر معين: while.

5. break وcontinue

break ينهي الحلقة فوراً. continue يتجاوز بقية التكرار الحالي وينتقل للتكرار التالي.

for i in range(1, 11):
    if i == 5:
        break
    print(i)
print("Loop ended")
# 1 2 3 4 ثم Loop ended

for i in range(1, 8):
    if i % 2 == 0:
        continue
    print(i)
# 1 3 5 7

while True

while True:
    text = input("Type 'exit' to quit: ")
    if text == "exit":
        break
    print(f"You typed: {text}")
print("Goodbye!")

6. الحلقات المتداخلة Nested Loops

لكل تكرار من الحلقة الخارجية، تنفذ الحلقة الداخلية كاملة.

for i in range(1, 4):
    for j in range(1, 4):
        print(i * j, end=" ")
    print()

# 1 2 3
# 2 4 6
# 3 6 9

المعامل end يغير ما تطبعه print في نهاية السطر. مثال: print("A", end="").

7. أنماط الحلقات الشائعة

  • Counter: عدّ عدد مرات حدوث شيء.
  • Accumulator: تجميع قيم في متغير total.
  • Search: البحث والتوقف عند العثور على القيمة باستخدام break.
count = 0
for i in range(1, 21):
    if i % 2 == 0:
        count += 1

total = 0
for i in range(1, 6):
    total += i

8. أمثلة مهمة

المضروب Factorial

n = int(input("Enter n (0 or more): "))
result = 1
for i in range(1, n + 1):
    result *= i
print(f"{n}! = {result}")
# عند n=5 الناتج 5! = 120

فحص العدد الأولي

number = int(input("Enter a number (> 1): "))
is_prime = True
for i in range(2, number):
    if number % i == 0:
        is_prime = False
        break
if is_prime:
    print(f"{number} is prime")
else:
    print(f"{number} is not prime")

مجموع الأرقام

number = int(input("Enter a positive number: "))
total = 0
while number > 0:
    digit = number % 10
    total += digit
    number //= 10
print(f"Sum of digits = {total}")
# 1234 => 10
